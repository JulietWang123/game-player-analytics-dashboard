# 玩家数据分析 · Dashboard

游戏玩家数据分析交互式报告，单 HTML 文件实现，数据内嵌、无后端依赖。

## 特性
- 4 个模块 Tab 切换（懒加载渲染图表）
- 浅色 / 深色主题一键切换（记忆偏好，默认跟随系统）
- Chart.js 4.4.1（CDN）绘制全部图表
- 数据一次性内嵌于页面，可直接离线打开

## 数据口径说明
- 活跃口径：近半年活跃（n=1,014）与近1年活跃（n=1,442）
- 风险人群模块仅展示地区/金额档的**群体聚合统计**，不含任何个人明细
- 项目名已脱敏

## 本地查看
直接浏览器打开 index.html 即可（图表需联网加载 CDN）。
